# Repository split

[`rlippmann/context-compiler-examples-integrations-ts`](https://github.com/rlippmann/context-compiler-examples-integrations-ts).

Use the [Python guide](python/README.md) for installation and validation.

the existing npm package identity while it moves toward the `0.2.0` release
boundary.
